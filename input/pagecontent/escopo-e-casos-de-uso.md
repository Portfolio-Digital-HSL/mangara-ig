# Escopo e Casos de Uso

## Escopo

Este guia cobre os recursos e perfis necessários para o domínio definido pelo projeto Mangara.

## Casos de Uso

- Cadastro e vinculação de profissionais
- Representação de papéis assistenciais
- Troca estruturada de dados entre sistemas

## Fora de Escopo

- Regras de negócio internas não representadas em FHIR
- Integrações fora dos perfis e extensões deste IG
