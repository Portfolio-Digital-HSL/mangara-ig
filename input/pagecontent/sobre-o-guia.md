# Sobre o Guia

## Objetivo

Definir os artefatos FHIR do projeto Mangara para padronizar troca de dados clínicos e administrativos.

## Público-alvo

- Equipes de integração
- Desenvolvedores de sistemas
- Arquitetos e analistas de interoperabilidade
- Equipes de governança de dados

## Dependências

Este guia utiliza como base o pacote `br.gov.saude.fhir.core#1.0.0` e FHIR R4 (`4.0.1`).

## Organização do Conteúdo

As páginas do guia estão divididas em escopo, artefatos de modelagem (perfis e extensões), exemplos e critérios de validação.
